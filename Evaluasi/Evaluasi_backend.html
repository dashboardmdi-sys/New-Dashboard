Yusen Dashboard Backend

Konfigurasi Data Source & Tampilan Dashboard Evaluasi
1. Sumber Data (Data Source)
Tentukan Google Sheet yang akan digunakan sebagai sumber data untuk dashboard.
Pastikan Google Sheet sudah di-set ke "Anyone with the link can view".
2. Rentang Data (Data Range)
Tentukan spesifik sheet dan cell range yang ingin diambil datanya.
Biarkan kosong jika mengambil dari sheet pertama.
Format range standar A1. Kosongkan untuk ambil semua.
3. Informasi Program (Header)
Sesuaikan teks yang muncul pada header dashboard laporan evaluasi.
Pengaturan berhasil disimpan!
